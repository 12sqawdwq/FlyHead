# DIABLO meshes

The STL meshes and `diablo_simulation.urdf` are unmodified files from
[DDTRobot/diablo_ros2](https://github.com/DDTRobot/diablo_ros2), package `diablo_simulation`, commit `ed0de02`,
licensed under Apache-2.0 (see `LICENSE` in this directory). They are the vendor's simulation meshes and have not
been checked against the physical robot. The 3D renders only use them to draw the robot.
