# 资源受限移动机器人的连续巡航与受约束路径跟踪

## 1. 论文方向

工作题目：**面向机载低算力移动机器人的连续巡航与平顺路径跟踪**。

英文工作题目：
**Continuous Patrol with Constrained Path Tracking on Resource-Limited Mobile Robots**

本文围绕一个问题组织方法与证据：
在机载定位、规划和控制共享计算资源的条件下，
如何减少多航点巡航中的非必要停车与反复转向，
同时保持既有速度上限和停车条件？

我们采用连续路段准备、受约束纯追踪、
带回差的转向状态机和协调速度变化，
将任务层的航点推进与控制层的运动切换分开处理。
该架构使用已有地图和机载位姿，
不依赖外部 GPU 或操作电脑参与导航计算。

论文定位以系统方法和机制实证为主。
RPP、回差和加速度约束均有既有研究基础，
不能把这些模块的简单组合直接视为算法首创。
可形成的贡献是：明确任务切换与运动约束的耦合问题，
给出轻量的协同实现，并以匹配对照解释各部分作用。
最终主张由实际实验结果确定，不预写改善幅度。

## 2. 系统与问题定义

机器人在二维地图上沿规划路径巡航。
控制状态为机体中心的位置和航向：

\[
\mathbf{x}_t=(x_t,y_t,\psi_t).
\]

控制输出为前向线速度和偏航角速度命令：

\[
\mathbf{u}_t=(v_t,\omega_t).
\]

A* 规划使用已有代价地图、机器人尺寸和高度信息。
控制器接收当前有效路径、定位状态与实时障碍信息，
经既有服务接口向底盘发送速度命令。
底盘平衡控制由机器人自身驱动负责。

操作电脑负责界面显示，不参与控制闭环。
固定地图显示与机载实时障碍处理是不同通道。
本文讨论经典导航控制，不将其描述为神经控制，
也不使用完整连接组仿真的研究结论支持本方法。

三个机制需要分别区分：

1. 航点切换清空路径造成的任务性停车。
2. 同一角度阈值反复触发造成的模式切换。
3. 速度命令超出约束后独立截断造成的转弯偏差。

定位延迟和底盘命令响应也会影响运动，
需要作为实验条件记录，而非默认归因于跟踪器。

## 3. 方法

### 3.1 连续巡航路径

规划器在同一代价地图上计算当前路段和下一路段。
两段仅在规划端点完全一致时连接，
不使用跨越障碍或未知区域的直线补齐间隙。
最后一个巡航路段可连接到返回出发点的路径。

设当前段与下一段分别为
\(P_i\) 和 \(P_{i+1}\)，准备路径为：

\[
P=P_i\oplus P_{i+1}.
\]

路径进度搜索限制在当前任务路段内，
防止跳到空间上相邻的未来路段。
到达中间航点时，任务层推进目标，
控制层保留剩余路径及速度历史。
下一段缺失时，控制器仍停车等待规划。

巡航终点减速参考已经准备路径的末端，
不把每个中间航点都当作最终停车位置。
此衔接保持路径位置连续，不保证切向或曲率连续；
急弯由曲率调速与转向状态机处理。

### 3.2 固定前视的 RPP 式曲率调速

本实现复用 RPP 的曲率调速思想，
不安装或宣称完整复现 Nav2 RPP 插件。
前视距离固定为 \(L=0.5\,\mathrm{m}\)。
控制器从当前段最近路径点起沿弧长取前视目标，
并在线段内插值，避免仅按离散索引跳选目标。
前视点可以跨过已经准备的中间航点。

记目标与机器人距离为 \(d\)，
目标方位相对当前航向的误差为 \(\alpha\)。
追踪曲率计算为：

\[
\kappa=\frac{2\sin\alpha}{\max(d,10^{-3})}.
\]

曲率调速使用最小调速半径 \(R_{\min}\)：

\[
v_{\kappa}=\frac{v_{\max}}
{\max(1,R_{\min}|\kappa|)}.
\]

当转弯半径小于 \(R_{\min}\) 时，
参考速度随曲率增大而降低。
当前取 \(R_{\min}=1.0\,\mathrm{m}\)。
它是初始工程参数，不是实机最优值。

已有障碍与终点速度限制保留：

\[
v_{\mathrm{obs}}=\max(0,(d_{\mathrm{free}}-0.6)\times0.5),
\]

\[
v_{\mathrm{goal}}=\max(0.04,0.5d_{\mathrm{end}}),
\qquad
v_{\mathrm{cap}}=\min(v_{\max},v_{\mathrm{obs}},v_{\mathrm{goal}}).
\]

长度单位为米，速度单位为米每秒。
巡航的 \(d_{\mathrm{end}}\) 是已准备路径的剩余弧长，
加上机器人到该剩余路径起点的距离。
其他任务沿用到目标的欧氏距离。
实际到达仍由既有到达判据触发零速，
不是依靠上式中的最小接近速度停车。

为避免仅截断角速度导致转弯半径变大，
跟踪参考命令满足：

\[
v^*=\min\left(v_{\kappa},v_{\mathrm{cap}},
\frac{\omega_{\max}}{|\kappa|}\right),
\qquad \omega^*=\kappa v^*.
\]

零曲率时省略角速度对应的线速度限制。
这里约束的是参考命令；
曲率变化时的加速度过渡不保证瞬时输出仍在同一曲率线上。

实时障碍检测沿用现有膨胀路径检查。
本轮没有新增 Nav2 RPP 的预测圆弧碰撞检查，
因此不据此提出完整扫掠轨迹无碰撞保证。

### 3.3 带回差和制动过渡的转向状态机

跟踪与原地转向使用两个阈值：

\[
\theta_{\mathrm{enter}}=40^\circ,
\qquad \theta_{\mathrm{exit}}=20^\circ.
\]

状态转换如下：

```text
TRACK
  │ |α| > 40°
  ▼
BRAKE_ROTATE ──命令降到近零──▶ ROTATE
                                  │ |α| ≤ 20°
                                  ▼
TRACK ◀────独立限幅平滑衔接─────────┘
```

`BRAKE_ROTATE` 将两通道参考命令设为零，
通过正常减速度限制降速。
退出转向时直接计算跟踪参考，不再先停顿到零角速度。
原地转向使用：

\[
v^*=0,
\qquad
\omega^*=\operatorname{clip}(1.5\alpha,
-\omega_{\max},\omega_{\max}).
\]

进入转向后保持该请求，直到误差满足退出条件。
恢复跟踪后，若误差再次超过进入阈值，
则重新进入转向制动。
近零判断阈值为命令量绝对值 \(10^{-6}\)。
这表示命令降至近零，不是轮速反馈确认物理静止。

普通路径刷新及连续航点推进不重置状态机。
新任务、取消、阻挡或到达等零速分支清空控制历史。
短暂定位过期仍立即清空速度命令，但保留转向模式；
恢复后从零命令重新加速。定位丢失或重建导航器时，
全部控制历史清空。
安全停车不等待转向制动状态完成。

### 3.4 协调的命令变化率约束

速度历史采用上一周期输出命令，
不将低频 SLAM 位姿差分伪装成高频轮速反馈。
控制间隔使用单调时钟，最大记账间隔为 0.2 s，
避免线程长时间停顿后一次积累过大的加速额度。
服务端标称控制周期为 0.1 s。

设上一命令为 \((v_p,\omega_p)\)，
参考差值为 \((\Delta v,\Delta\omega)\)。
根据加速或减速选择对应限值 \(a_v,a_\omega\)，
对两个通道分别施加变化率约束：

\[
v=v_p+\operatorname{clip}(\Delta v,-a_v\Delta t,a_v\Delta t),
\]

\[
\omega=\omega_p+\operatorname{clip}(\Delta\omega,-a_\omega\Delta t,a_\omega\Delta t).
\]

独立限幅避免线加速约束拖延角制动。
它不是 DWPP 的动态窗口优化，
不保证过渡期间严格保持参考曲率。
先前共同插值实现的现场记录作为故障证据保留，
不用于支持当前实现的性能主张。
若角速度目标与当前命令异号，
先以零角速度为过渡目标，再允许反向加速。

| 参数 | 初始值 | 含义 |
|---|---:|---|
| 线加速度 | 0.10 m/s² | 命令增加率上限 |
| 线减速度 | 0.20 m/s² | 正常命令减少率上限 |
| 角加速度 | 0.80 rad/s² | 角命令幅值增加率上限 |
| 角减速度 | 1.20 rad/s² | 正常角命令幅值减少率上限 |
| 默认线速度上限 | 0.10 m/s | 保持既有默认值 |
| 默认角速度上限 | 0.40 rad/s | 保持既有默认值 |

已有界面可设置的速度范围不变。
上述加速度是命令约束，不能直接解释为底盘实测加速度。
站立与匍匐的命令响应应在证据中分别记录。

### 3.5 停车与约束优先级

约束顺序是：
**既有停车条件 → 硬速度上限 → 正常平顺性约束**。

底盘不可用、定位失效或过期、既有遮挡判据、
路径阻挡、暂停及任务到达等分支直接返回零命令。
它们绕过加速度平滑，不延迟已有停车请求。

正常输出若超出新收紧的线／角速度上限，
两个通道使用同一比例缩小。
这种硬限幅可优先于正常减速度约束，
由状态字段单独标记。
加速度统计应分别报告正常控制与保护触发片段，
同时保留包含停车事件的整段统计。

## 4. 面向短论文的证据组织

本节是后续研究设计，不是已冻结的执行协议。
中心假设是：任务衔接与运动切换的协同，
能减少非必要停转，而不仅是把所有速度降低。

### 对照与消融

建议在相同地图、路线、速度上限和停车条件下比较：

| 条件 | 用途 |
|---|---|
| 旧离散航点＋原跟踪器 | 项目历史行为基线 |
| 连续航点＋原跟踪器 | 分离航点衔接作用 |
| 连续航点＋完整组合 | 评估整体系统 |
| 完整组合去除曲率调速 | 检查急弯速度协调 |
| 完整组合去除转向回差 | 检查阈值附近切换 |
| 完整组合去除加速度约束 | 检查命令变化率作用 |
| 上游 RPP 配置或明确的匹配移植 | 建立成熟方法参照 |

所有条件保留同一套停车保护。
消融不允许通过放宽障碍阈值换取连续性。
比较上游 RPP 时记录发行版、提交、配置与接口差异，
不能把本项目裁剪实现标成完整官方插件。

### 场景与指标

场景至少区分直线、多航点闭环、直角／连续弯道、
初始大航向误差与受控障碍停车。
站立和匍匐条件分层报告，不混成一个速度响应模型。

核心指标：

- 每米非必要停车次数及停留时间。
- 单位距离模式切换次数和角速度反向次数。
- 横向跟踪误差的 RMSE、P95 与最大值。
- 正常片段和整段命令变化率。
- 到达率、完成时间和人工接管次数。
- 最小障碍间距及保护停车事件。
- 控制计算时延、循环间隔与位姿源龄分布。

需要预先定义“停车”“非必要”和“反向”的阈值，
不能看到结果后调整定义以去除不利事件。
安全停车单独归类，但不能从完整运行记录中删除。
定位输出上的跟踪误差与独立参考轨迹误差分开命名。
没有独立真值时，不将内部误差当作物理精度证明。

以一次完整运行作为统计单位，
不同方法使用匹配的路线和起始条件，随机化运行顺序。
正式采集前确定路线数量、重复次数、时间预算、
调参／评估划分、停止规则及统计方法。
不把相邻控制周期当作独立实验重复。
