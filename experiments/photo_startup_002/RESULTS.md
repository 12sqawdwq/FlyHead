## 前进启动通路

新增179个精确匹配的LC9视觉投射细胞，
与原6个HS构成185个感觉代理输入。
P9和其他行为读出不接受直接外部刺激。

完整固定图中，左P9接收50个LC9的非零连接，
右P9接收64个；带符号权重和分别385、866。
这不是两侧相同的对称人工网络。

LC9全组50、100、200Hz三个剂量，
均在本次模拟中招募了P9，且平均发放随剂量增加。
对应三种子平均影子前进速度约为
0.010、0.033、0.098m/s。
这说明模型内的间接启动路径有响应，
不是通过刺激P9或给速度加常量得到的结果。

## 两张照片的响应

输入来自scikit-learn固定提交的公开照片，
不是机器人实拍；许可和署名见photos/README.txt。
每照片含静态、人工左移4像素和人工右移4像素，
分别测试HS_ONLY、LC9_ONLY和COMBINED。

加6个刺激控制和1个均匀灰图，
共25条件×3种子，每次500ms，共75次。
均保留完整138639神经元和15091983连接。

下表为COMBINED的三种子平均值。
发放率是500ms窗口计数换算，不是语义分类概率。

| 输入 | P9左/右 Hz | DNa02左/右 Hz | 影子v m/s | 影子ω rad/s |
| --- | --- | --- | --- | --- |
| 建筑静态 | 83.3 / 119.3 | 4.0 / 0.0 | 0.100 | +0.012 |
| 建筑左移 | 90.0 / 114.0 | 35.3 / 0.0 | 0.099 | +0.106 |
| 建筑右移 | 86.7 / 114.7 | 4.7 / 5.3 | 0.099 | -0.002 |
| 花卉静态 | 77.3 / 91.3 | 2.0 / 0.0 | 0.084 | +0.006 |
| 花卉左移 | 80.0 / 90.7 | 36.0 / 0.0 | 0.085 | +0.108 |
| 花卉右移 | 78.0 / 93.3 | 2.0 / 9.3 | 0.086 | -0.022 |
| 均匀灰图 | 0 / 0 | 0 / 0 | 0 | 0 |

静态照片只用HS时，P9及固定行为读出均为零。
加入LC9后P9出现响应，构成启动支路的消融证据。
LC9_ONLY不包含运动编码，因此同一照片的
静态和左右平移条件得到相同结果是预期的，
不能当成三个独立自然场景的泛化结果。

启动支路会影响转向，而不是简单叠加。
HS_ONLY右移的影子ω均值为-0.058rad/s，
COMBINED建筑右移降至-0.002rad/s。
当前尚不能假定前进开启后左右转向依然对称。
