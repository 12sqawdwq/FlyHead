# 启动通路、推理加速与照片响应

当前用户授权在5090D执行本轮开发与响应测试。
只使用公开照片，不读取机器人历史私有照片。
不调用真实相机、ROS或底盘。
不改mapping_001冻结记录，不自动外发。

本轮顺序：

1. 查证视觉输入到前进启动候选通路的依据。
2. 固定照片、细胞集合、编码和测试条件。
3. 对原始方程的CUDA执行做等价加速。
4. 逐项核对全脑计数和状态，再测试照片。
5. 生成神经元级表格和可查看的响应报告。

照片静态展示、照片人工平移和启动刺激独立标记。
不将静态照片说成真实运动序列，
不将神经活动说成语义识别或真实机器人行为。

代码、输入和评价规则将在执行前锁定。
正式配置见后续PROTOCOL.md。
