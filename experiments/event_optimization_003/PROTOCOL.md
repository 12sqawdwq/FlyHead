# 完整图事件传播优化

目的：减少每0.1ms扫描整个稀疏权重矩阵的开销。
这是用户本轮推理优化授权内的独立技术探针。
mapping_002照片结果保持冻结，不追溯改用新后端。

全部138639神经元和15091983连接保留。
把权重转为按源神经元排列的完整CSR索引。
每步在GPU压紧当前尖峰源，动态遍历全部活动源。
活动列表容量为全脑神经元数，不截断活动细胞。

先验证所有权重是整数，每个目标的绝对权重和
不超过2^24-1；否则拒绝该优化，不改权重。
在此条件下，0/1尖峰乘整数权重的累加
可用int32精确计算，再转回FP32。
Poisson采样、LIF、延迟、不应期及wScale均不变。
不是量化近似，也不改变外部刺激或动力学。

基准使用mapping_002固定185输入和原注册表。
比较未修改上游eager、CUDA Graph事件后端。
ZERO、HS_LEFT、HS_RIGHT、LC9_200，
以及两张照片STATIC_COMBINED共6个固定输入。
每条件500ms，seed=20260923，各自独立初态。

等价门：全脑计数完全一致；五个末状态
绝对误差<=1e-5，全部有限；保留原始数组。
门失败即不接受事件后端，不改阈值重试。

通过后对HS_LEFT和LC9_200分别计时，
每后端1次预热＋10次100ms，全部样本报告。
共享GPU下只作描述性比较，不做独占或实机验收。
不重跑75次照片结果来替换旧数据。

预算：CPU4线程，RSS6GiB，GPU分配器1GiB。
启动空闲GPU5GiB、主机20GiB、磁盘40GiB。
执行中主机空闲12GiB、GPU空闲2GiB保护门。
300秒墙钟；只停止自身进程，不改其他任务。
Triton缓存仅写本目录，不安装或修改原环境。
若资源、编译或CUDA失败，保留失败并停止。
不自动重试，不启动ROS／机器人或发送外部消息。
