# 连续视频刺激

首先打开VIDEO_RESPONSE.html。
播放视频或拖动滑条，可同步查看逐帧读出和响应曲线。
可切换16个回合：两视频、四条件、两种子。
8秒为真实视频刺激，8–9秒为零输入尾段。
冻结控制显示冻结首帧，不显示成移动输入。

- RESULTS.md：结论、实时预算及编码局限。
- FRAME_RESPONSES.csv：1440个窗口逐项数据。
- run_001/：全脑计数、10ms读出分箱和末状态。
- inputs/：固定解码帧、媒体PTS和播放预览。
- VIDEO_RESPONSE_PREVIEW.png：实际浏览器预览。

本轮已验证持续状态下的动态输入计算，
