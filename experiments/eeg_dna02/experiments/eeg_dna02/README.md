# EEG → DNa02 离线实验

此入口只加载神经模型和本地预测文件，不导入 ROS/底盘/网络客户端，也不注册后台服务。

## 运行身份

分支 feat/eeg-dna02-calibration。原 decoder.py 字节保持不变，固定 DecoderV4。神经注册表未改写，由 layout() 从原 readouts 中解析左右 DNa02，并追加到独立刺激向量。原 LC 输入索引仍用于零不应期设置；新 DNa02 保持上游 22 步（2.2ms）不应期，运行时断言验证。

## 已实现

- EEG 输入概率校验、阈值0.8、序号和年龄门控、显式禁用。
- rate_left=40*max(pL-pR,0)，rate_right=40*max(pR-pL,0)。40 Hz 为预先固定的实验增益，不代表最终校准结论。
- 每窗口清零刺激缓冲再写入，防止撤销后残留输入；保持神经内部状态连续。
- 左右刺激 10/20/40/80 Hz × 三个种子，每组1秒刺激＋0.5秒撤销观察；每组之间重置状态。
- 从 TCFormer seed0_subject01 的真实 predictions.npz 中，各真实类别按原顺序选前20条，再按试验索引排序。概率来自已保存推理结果，本轮不重新运行 TCFormer。
- EEG 片段之间重置神经状态，片段内连续；时间戳为受控回放时钟，不是当前在线采集时间。该实验不能证明真实网络延迟或连续脑控安全性。

## 未接入的内容

没有修改在线 brain_service.py、导航后端、网页或 EEG 网络发送器；没有启用雷达联合输入，没有把意图发送到机器人。它是可调用输入编码模块和完整连接组离线验证入口，不是已上线的 EEG 控制服务。
